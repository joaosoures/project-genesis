# Skills do Projeto

Esta pasta contém documentos que definem as regras permanentes e padrões de implementação do projeto.

## Como utilizar

- Cada arquivo `.md` nesta pasta representa uma "Skill" (habilidade ou regra específica).
- Qualquer alteração de código ou implementação de nova funcionalidade deve consultar as skills aplicáveis **ANTES** de começar.
- As regras contidas nestes documentos devem ser seguidas rigorosamente para manter a consistência e integridade do projeto.
